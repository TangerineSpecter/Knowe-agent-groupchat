# 技能、MCP 与资料空间

这三个功能同时适用于桌面端和单用户网页版。网页端的安装目录、命令和文件均位于运行 Knowe 的服务器或容器中。

## 技能包

进入“知识库 → 第三方技能包 → 安装技能”，可粘贴公开 GitHub 仓库、技能子目录或 SKILL.md 地址，也可导入 ZIP。预览会列出实际发现的技能、说明及同名冲突，勾选后安装；替换已有技能需要明确选择。更新沿用原有生效、待审或退役状态。详情面板继续提供状态切换和卸载。

手动安装：展开安装面板的“手动安装”，把含 `SKILL.md` 的技能文件夹复制到显示的目录，保留 `scripts`、`references`、`assets` 等资源。默认第三方目录是数据目录下的 `skills/third_party`；可通过 `KNOWE_THIRD_PARTY_SKILLS_DIR` 设置。系统提供 `project-report`、`research-summary` 两个技能。

技能采用 Agent Skills 的 YAML 头部格式，需要 `name` 和 `description`，支持多行说明。安装器检查压缩包路径、符号链接、大小与文件数量。ZIP 最大 32 MiB，解压后最大 96 MiB、4,000 个文件；单个 SKILL.md 最大 512 KiB。安装和读取不会自动运行脚本或安装包内依赖。

在项目群聊或成员私聊的输入框输入 `/`，搜索技能名称或说明，使用方向键和 Enter/Tab 选择；Esc 关闭。选中的技能显示在输入框上方，可移除，每条消息最多 8 个。技能正文及资源位置会进入本次任务，并随主管交接给执行成员。技能资源在项目 `.knowe-skills` 下形成快照，避免不同项目共享可写资源；这些资源不参与自动交付文件扫描。知知会话没有项目工作目录，不提供手动技能选择，仍可按用户要求安装技能。

Agent 可以通过 `list_skillpacks`、`read_skillpack` 按任务自行发现和加载已生效技能。`user-invocable: false` 隐藏手动入口；`disable-model-invocation: true` 隐藏自动发现入口。用户明确要求安装时，Agent 可使用预览和安装工具处理 GitHub 地址，知知也可进行安装。停用或卸载后的技能不能再次加载；已进入运行中任务的上下文不会被中途撤销。

GitHub 安装目前面向公开仓库。私有仓库可在有权限的环境下载 ZIP 后导入。含 `/` 的分支名可使用 URL 编码的 ref；通用 Git 托管地址、私有仓库登录及外部技能市场命令不作为下载入口。脚本依赖按技能说明在运行环境中安装。

## MCP 连接

进入“知识库 → 第三方技能插座”，支持：

- Streamable HTTP：填写服务地址，可设置 JSON 请求头，例如 Bearer Token。
- SSE：兼容使用旧传输方式的服务。
- stdio：填写可执行命令、JSON 参数数组、可选启动目录和环境变量。命令在 Knowe 所在机器上执行，参数不经过 shell 拼接。
- 导入配置：接受常见的 `{"mcpServers": {...}}` 配置，整体校验后写入；重复名称需要修改或编辑原连接。

保存后点击“测试连接 / 查看工具”，查看服务实际声明的工具、说明和参数。可以启停连接、编辑、删除，或逐项关闭工具。默认允许全部工具；取消“允许全部工具”后，只允许当前选定的工具，后续新增工具不会自动获得使用权限。测试仍展示完整目录，便于重新开启。

密钥保存在数据目录 `extensions/mcp.json`，文件权限为 0600，不在管理列表和编辑表单回显。编辑时密钥留空保留原值，填写 `{}` 清空。当前提供请求头 Token 认证；需要交互式 OAuth 登录的服务应先通过其支持的 Token 方式配置，本版没有 OAuth 授权页面。

执行 Agent 通过 `list_mcp_tools` 获取真实 schema，再使用 `call_mcp_tool` 调用。主管只发现工具，实际调用由执行成员完成。工具禁用、连接停用和参数校验在后端执行。连接保持会话状态；空闲 5 分钟关闭，下次使用重新建立；超时调用不自动重试，避免重复外部操作。活动记录中可查看工具使用。没有可用服务时显示明确错误，不把失败报告成成功。

当前安装包没有预置系统 MCP 服务，系统页会如实显示空状态。添加 stdio 服务前，需要在服务器或电脑上准备其运行环境。

## 资料空间

左侧新增“资料空间”，集中收录网页上传的附件、聊天中返回的 Agent 文件，以及桌面端已发送的本地附件引用。已有聊天的文件卡片会回填索引，后续文件随消息自动入库。索引引用原文件，不额外复制一套。

可以搜索文件名，按项目、来源、收藏筛选，按修改时间、大小或名称排序，预览、下载（网页）或在文件夹中显示（桌面），并展开来源跳转到聊天。支持选择本页文件批量处理。

存储数值是“已收录受管文件”的大小，包含网页上传和 Agent 产出，不代表整块磁盘或整个项目目录的大小。本地外部引用不计入受管空间。文件被外部编辑或移走后，刷新会更新大小或标记缺失。

- 网页上传和项目产出：移入回收站会将文件移离原路径，聊天卡片暂不可用；恢复放回原位置，不覆盖同名文件。只有彻底删除才释放回收站空间。
- 本地引用：移除、恢复和彻底删除只操作资料记录，不删除用户电脑上的原始文件。
- 删除前展示引用影响；关联项目仍在执行任务、文件在列表加载后已变化、目标路径异常时会拒绝操作。
- 批量操作逐项返回成功和失败，不把部分失败显示成全部完成。
- 网页输入框中移除未发送附件时，服务端只清理无聊天引用的上传。关闭页面遗留的文件可在“未引用的上传”中找到并清理。

文件原名、来源关系和回收站状态存放在数据目录 `library/catalog.sqlite3`；回收站实体在 `library/trash`。移动操作有过渡状态，重启会修复未完成记录。备份时需要同时保存数据目录和工作目录。资料空间不自动清理历史文件，也不会扫描删除项目中未收录的其他文件。

预览沿用已有预览器和 64 MiB 预览上限；网页下载直接流式返回文件，不受该预览上限约束。
